# cpp-beginner-projects

## 📖 Overview
This repository contains beginner-friendly C++ projects created while learning programming fundamentals.

It is designed to practice:
- Input / Output
- Conditional statements
- Loops
- Switch-case
- Basic validation and calculations

---

## ⚙️ Repository Structure
Each `.cpp` file is an independent console program.

### 📂 Projects
- **Bill_Splitter.cpp** – Split a bill among multiple people.
- **Cutoff_Checker.cpp** – Check pass/fail with overall and subject cutoffs.
- **Day_Name_And_Type.cpp** – Find day name and identify weekday/weekend.
- **Electricity_Bill_Calculator.cpp** – Calculate bill using unit slabs.
- **Grade_Evaluator.cpp** – Evaluate grade from marks.
- **Mini_ATM.cpp** – Basic ATM simulation (balance, deposit, withdraw).
- **Movie_Ticket_Counter.cpp** – Calculate ticket amount by category.
- **Petrol_Pump_Dispensor.cpp** – Fuel billing by amount or liters.
- **Simple_Calculator.cpp** – Perform basic arithmetic operations.
- **Smart_Card_Fare_System.cpp** – Metro fare and balance check system.
- **Table_Maker.cpp** – Generate multiplication tables.
- **Temperature_Converter.cpp** – Convert Celsius and Fahrenheit.
- **Voting_Eligibility_Checker.cpp** – Check voting eligibility by age.
- **Water_State_Checker.cpp** – Determine water state from temperature.

---

## 🛠️ Requirements
- A C++ compiler (e.g., `g++`)
- Terminal / command prompt

---

## ▶️ How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/yash-kumar-18/cpp-beginner-projects.git
   cd cpp-beginner-projects
   ```

2. Compile any file (example: `Simple_Calculator.cpp`):
   ```bash
   g++ Simple_Calculator.cpp -o Simple_Calculator
   ```

3. Run the program:
   ```bash
   ./Simple_Calculator
   ```

4. Repeat the same steps for any other `.cpp` file.
