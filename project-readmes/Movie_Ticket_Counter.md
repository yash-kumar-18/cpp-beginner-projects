# Movie_Ticket_Counter.cpp

## Overview
This project calculates movie ticket total based on screen type, age, and number of persons.

## How It Works
- Lets user select ticket category:
  - Standard
  - IMAX 3D
  - VIP Lounge
- Accepts age and number of tickets.
- Applies VIP pricing with senior-citizen discount for age 60+.
- Validates menu choice, age, and ticket count.
- Prints total payable amount.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Movie_Ticket_Counter.cpp -o Movie_Ticket_Counter
./Movie_Ticket_Counter
```
