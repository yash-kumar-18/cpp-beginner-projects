# Mini_ATM.cpp

## Overview
This project simulates basic ATM operations with a starting balance.

## How It Works
- Starts with a default balance of 1000.
- Shows menu options: check balance, deposit, withdraw, exit.
- Validates positive deposit/withdrawal amounts.
- Checks balance before withdrawal.
- Prints result based on selected option.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Mini_ATM.cpp -o Mini_ATM
./Mini_ATM
```
