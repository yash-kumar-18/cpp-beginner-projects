# Cutoff_Checker.cpp

## Overview
This project checks pass/fail status using overall marks and individual subject cutoffs.

## How It Works
- Accepts theory and practical marks.
- Validates both marks are between 0 and 50.
- Checks overall cutoff (total at least 40).
- Checks individual cutoffs (theory and practical at least 15 each).
- Prints pass/fail reason.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Cutoff_Checker.cpp -o Cutoff_Checker
./Cutoff_Checker
```
