# Voting_Eligibility_Checker.cpp

## Overview
This project checks whether a person is eligible to vote based on age.

## How It Works
- Accepts age input.
- Validates age is greater than zero.
- If age is below 18, prints not eligible.
- If age is 18 or above, prints eligible.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Voting_Eligibility_Checker.cpp -o Voting_Eligibility_Checker
./Voting_Eligibility_Checker
```
