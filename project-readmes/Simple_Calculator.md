# Simple_Calculator.cpp

## Overview
This project performs basic arithmetic operations between two numbers.

## How It Works
- Accepts two numbers.
- Accepts an operator (`+`, `-`, `*`, `/`).
- Uses `switch` to run the selected operation.
- Handles division by zero with an error message.
- Shows error for invalid operator input.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Simple_Calculator.cpp -o Simple_Calculator
./Simple_Calculator
```
