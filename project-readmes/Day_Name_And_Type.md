# Day_Name_And_Type.cpp

## Overview
This project maps a day number (1 to 7) to day name and identifies weekday/weekend.

## How It Works
- Accepts a day number input.
- Uses `switch` to print the corresponding day name.
- Validates valid range (1 to 7).
- Uses another `switch` to print whether the day is a weekday or weekend.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Day_Name_And_Type.cpp -o Day_Name_And_Type
./Day_Name_And_Type
```
