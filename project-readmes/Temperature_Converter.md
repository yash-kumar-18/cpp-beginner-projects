# Temperature_Converter.cpp

## Overview
This project converts temperature between Celsius and Fahrenheit.

## How It Works
- Lets user choose conversion direction:
  - Celsius to Fahrenheit
  - Fahrenheit to Celsius
- Validates conversion option.
- Performs selected conversion formula.
- Supports repeated calculations using `y/n` prompt.
- Validates repeat input.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Temperature_Converter.cpp -o Temperature_Converter
./Temperature_Converter
```
