# Bill_Splitter.cpp

## Overview
This project splits a total bill amount among multiple people.

## How It Works
- Takes total bill amount as input.
- Takes total number of persons.
- Validates that persons are not zero.
- Calculates and prints bill per person.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Bill_Splitter.cpp -o Bill_Splitter
./Bill_Splitter
```
