# Water_State_Checker.cpp

## Overview
This project determines the physical state of water from input temperature.

## How It Works
- Accepts water temperature in Celsius.
- If temperature is below 0, output is solid state.
- If temperature is 100 or above, output is gaseous state.
- Otherwise, output is liquid state.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Water_State_Checker.cpp -o Water_State_Checker
./Water_State_Checker
```
