# Grade_Evaluator.cpp

## Overview
This project evaluates grade based on entered marks.

## How It Works
- Accepts marks input.
- Uses `if/else if` ranges to assign grades:
  - A: 90 and above
  - B: 75 to 89
  - C: 50 to 74
  - D (Pass): 33 to 49
  - F (Fail): below 33
- Prints the grade.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Grade_Evaluator.cpp -o Grade_Evaluator
./Grade_Evaluator
```
