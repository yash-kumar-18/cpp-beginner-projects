# Table_Maker.cpp

## Overview
This project generates a multiplication table for a given number.

## How It Works
- Accepts a number for table generation.
- Accepts a limit up to which table should be printed.
- Validates that number is greater than zero.
- Uses a loop to print multiplication results from 1 to limit.

## Requirements
- C++ compiler (`g++`)
- Terminal

## Compile & Run
```bash
g++ Table_Maker.cpp -o Table_Maker
./Table_Maker
```
